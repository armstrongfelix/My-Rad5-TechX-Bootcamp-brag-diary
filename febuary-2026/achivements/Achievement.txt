1. learnt how to do responsiveness using css grid;
    a. repeat(auto-fit, minmax(200px, 1fr));

    **What this does:**

    - `repeat()`: Creates repeating columns
    - `auto-fit`: Creates as many columns as will fit
    - `minmax(200px, 1fr)`: Each column is minimum 200px, maximum 1fr
    - Result: Automatically responsive! On wide screens: many columns. On narrow screens: fewer columns.

    e.g:
        .gallery {
            display: grid;
            grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
            gap: 20px;
            padding: 20px;
        }

9.  header
        A <header> element can be used multiple times — once as a page-level landmark and again inside <article> or <section>. Here it is the page-level hero. Placing <main> content inside <header> would be wrong; the hero is genuinely a header/introduction to the page.

10. Table:
        HTML Table anatomy — memorise this
        <table> wraps everything. <thead> holds the header row. <tbody> holds all data rows. <tr> is a table row. <th> is a header cell (bold, centred by default). <td> is a data cell. Always include <thead> and <tbody> — they allow separate styling and help screen readers understand the structure.

11. color: inherit;
        This is a very clever way to manage your site's color palette.
        The Default: Links are usually "Royal Blue" by default, and turn "Purple" once you've clicked them.
        The "Inherit" Trick: Instead of forcing a specific color, inherit tells the link to take the color of its parent element.
